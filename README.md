# D-JIVA: Dynamic Joint Information-Vector Architecture

Численная реализация архитектуры **D-JIVA (ДЖИВА)** — формализм когерентной самоорганизации для пребиотических и сложных систем.

## Связь с препринтом
Код является практической частью препринта:
**«ДЖИВА (D-JIVA): Архитектура динамических совместных информационных векторов»** (Кузнецов Г.М., preprints.ru, 2026).

## Ключевые операторы
* **Ω (Оператор Ю)** — эволюционный отбор (движение к аттрактору).
* **H (Оператор ЖДЫ)** — информационная энтропия (подавление мутаций).
* **D (Оператор НА)** — квантовая декогеренция (нелокальность).
